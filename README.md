# 能听懂人话的小车

> STM32 下位机 + 树莓派上位机 + 大模型决策层的语音控制小车

## 项目目标

用一句自然语言指令（比如"绕过桌子去门口"）控制小车完成动作。

分层设计：

| 层 | 硬件 | 职责 |
|---|---|---|
| 决策层 | 大模型 | 把自然语言拆解成动作序列 |
| 上位机 | 树莓派 4B | 语音识别、指令下发、状态显示 |
| 下位机 | STM32F103C8T6 | 实时运动控制、传感器采集 |

## 硬件平台

- 主控：STM32F103C8T6（Cortex-M3）
- 上位机：Raspberry Pi 4 Model B（4GB RAM）
- 电机驱动：L298N
- 传感器：红外避障模块

## 目录结构

| 目录 | 内容 |
|---|---|
| `User/` | `main.c` 主程序入口 |
| `Hardware/` | 驱动层：Car / Motor / PWM / Serial / OLED / Key / LED |
| `System/` | 延时函数 |
| `Start/` `Library/` | STM32F10x 标准外设库与启动文件 |
| `project.uvprojx` | Keil MDK 工程文件 |
